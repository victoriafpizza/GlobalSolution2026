# Matriz de responsabilidade compartilhada

Escopo em 12/11/2026. O ROTA LIVRE roda em uma instância Amazon EC2 na região de Ohio, `us-east-2`. GitHub e a estação de observabilidade aparecem na matriz para explicitar os limites da operação. Os controles herdados são responsabilidades documentadas pela AWS. Os controles do projeto foram classificados com base no código e nas evidências operacionais disponíveis. [Modelo de responsabilidade compartilhada da AWS](https://aws.amazon.com/pt/compliance/shared-responsibility-model/)

O uso de EC2 deixa a segurança do sistema convidado, dos dados e da configuração lógica sob responsabilidade do projeto. A existência de recursos AWS como snapshots e armazenamento de logs descreve capacidade do serviço. A comprovação de cada controle exige evidência de configuração ou execução no ambiente do projeto.
